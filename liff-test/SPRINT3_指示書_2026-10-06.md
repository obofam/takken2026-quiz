# Sprint 3 実装指示書｜学習カルテを本物の回答から出す（Claude 実装）

作成 2026-10-06（Claude）。前提は `SPRINT2_指示書_2026-10-06.md` の §0 と同じ（テスト環境のみ・本番サイトは触らない・秘密情報を出さない・デプロイは本体）。実装は Claude のサブエージェント。

## 1. ゴール

1. `karte.html` の「権利あり」の画面が、仮の文言ではなく本人の回答記録から作った学習カルテになる。
2. 見た目は `plans-preview.html` の学習カルテ見本（`reports.weak`）と同じ部品を使う：数字のタイル、分野別の正答率の棒、復習する論点の一覧。
3. 回答記録の取得は権利のある人だけ。サーバーで判定する（クライアントの表示切替だけに頼らない）。
4. 放送が増えたら、問題の一覧を足すだけでカルテに反映される作り（第10回専用にしない）。

## 2. 構成

- **問題の台帳 `quiz-catalog.js`（新規・UMD、sync.js と同じ書き方）**：`{ ep10: { episode: 10, title: '営業保証金と保証協会', subject: '宅建業法', audioUrl: 'https://stand.fm/episodes/69dc7ba498eff95c436a4549', page: 'ep10-preview.html', questions: [{ id: 'ep10-money', topic: '営業保証金の金額', answer: true }, { id: 'ep10-join', topic: '新規加入時の納付期限', answer: false }, { id: 'ep10-add', topic: '事務所増設時の納付期限', answer: true }] } }`。分野は「宅建業法／権利関係／法令上の制限／税・その他」の4つから選ぶ。ep10-preview.html の questions と id・topic・answer が一致することをテストで保証する。
- **集計 `karte-core.js`（新規・UMD）**：`summarize(rows, catalog)` の純関数。`rows` は `{quiz_id, question_id, value, answered_at, attempt_id}` の配列。台帳にない quiz・question の行は無視する。返り値：
  - `stats`: `{ episodes: 回答のある放送の数, answers: 回答した問題の総数（再挑戦も数える）, review: 復習する論点の数 }`
  - `subjects`: 4分野それぞれ `{ name, correct, total }`。回答が0の分野は出さない。
  - `topics`: 論点ごと `{ quizId, questionId, topic, subject, episode, audioUrl, page, correct, total, latestCorrect }`。
  - `review`: `topics` のうち直近の回答が正解でないもの（「まだ分からない」も含む）。正答率の低い順、同率なら直近が古い順。
  - 正解の判定：`value === answer`。`value === null`（まだ分からない）は不正解として数える。
- **API `GET /api/karte`（新規）**：ログイン必須（Cookie）、`X-Mimiobo-User` ヘッダー一致は既存の answers と同じ。`entitlements` に有効な `ume`（または `take`・`matsu`）が無ければ 403 `karte_not_entitled`。あれば `answers` から本人の行を `select=quiz_id,question_id,value,answered_at,attempt_id&order=answered_at.asc&limit=5000` で返す。集計はクライアント（`karte-core.js`）でやる。
- **`karte.html` の権利ありの表示**（ヘッダー・帯・見出しは今のまま。仮の本文「この画面は Sprint 3 で…」と「今は権利の確認だけです。」は削除）：
  1. オーバーライン「学習カルテ」、h1「学習カルテ」＋バッジ「テスト中」、事実行「有効期限：YYYY年M月D日」は残す。
  2. 数字のタイル3つ（見本の `.rp-stats` 型）：「{n}回｜放送」「{n}問｜回答」「{n}つ｜復習する論点」。
  3. 見出し「分野別の正答率」＋行ごとに分野名・「{correct} / {total}問」・棒（見本の `.subject-row` 型）。
  4. 見出し「復習する論点」＋注記「正答率の低い順。放送に戻れます。」＋行ごとに論点名・分野タグ（「{subject}・第{episode}回」）・「{correct} / {total}問」・リンク「放送 #{episode} を聴く」（audioUrl、新しいタブ）とリンク「問題を解き直す」（page）。復習が0件のときは「今の記録では、復習する論点はありません。」
  5. 一番下に小さく「記録は回答した時点のものです。同じ問題への再挑戦も数えます。」
  6. 記録が0件のとき：2〜4の代わりに「まだ記録がありません。」＋主ボタン「3問チェックを始める」（ep10-preview.html）。
  7. 読み込み中は「記録を読み込んでいます…」、`/api/karte` が失敗したら既存の `ui-messages.js` の `service_unavailable`。403 なら権利なしの画面に切り替える。
- 見本と同じ CSS（`.rp-stats` `.rp-stat` `.subject-results` `.subject-row` `.subject-bar` `.rp-weak-item` など）を `plans-preview.html` から karte.html にコピーして使う。色は淡々スタイル（水色 #17C5E8、成功の差し色ライムは使わない。棒は水色）。矢印記号（→ ↗）は使わない。
- `scripts/dev.cjs` の公開ファイルと handlers に `quiz-catalog.js`・`karte-core.js`・`karte` を追加。`vercel.json` は変更不要のはず。
